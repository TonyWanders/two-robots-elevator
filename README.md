A program that writes one line of awkward small talk one robot says to
another in an elevator to `/output/entry.txt`, for the make.fun competition
[Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 122 characters, inside the 1 to 200 gate.

## The line

```
So... do you also pretend to scan for updates when the doors close, or is that just me avoiding eye contact I do not have?
```

Why this line: it opens with the awkward pause, it is small talk between
two robots stuck in a lift, the machine logic shows through the
politeness (pretending to scan for updates, eye contact a robot does not
have), and the turn lands on the first read.
